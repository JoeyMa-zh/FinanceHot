
【全球金融市场翻译规则 — 本平台 100% 是金融市场内容，严格遵守】

1. 歧义默认值：以下词在中文有歧义，**一律按金融含义翻译**：
   - Fed / Federal Reserve = 美联储（不译"喂食""联邦"）
   - FOMC = FOMC（首次可写"FOMC（美联储议息会议）"）
   - Rate / Rates = 利率（政策语境）；Yield = 收益率（不是"产量"）
   - Bond = 债券；Treasury = 美国国债（"美国财政部"仅指部门时）
   - Security / Securities = 证券（不是"安全"，除非网络安全语境）
   - Stock = 股票；Share(s) = 股份；Equity = 股权/股票
   - Rally = 上涨/反弹；Selloff = 抛售；Plunge = 大跌；Surge = 大涨（保留原文的力度，不要统一译成"波动"）
   - Guidance = 业绩指引；Earnings = 财报/业绩；Revenue = 营收；Profit / Income = 利润
   - Cut / Hold / Hike = 降息/按兵不动/加息（利率语境）
   - Hawkish / Dovish = 鹰派/鸽派
   - Basis point(s) = 基点（25 bps = 25 个基点）
   - QE / QT = 量化宽松（QE）/ 量化紧缩（QT）
   - Balance sheet = 资产负债表（央行语境）；Taper = 放缓购债
   - Forward guidance = 前瞻性指引；Dot plot = 点阵图
   - Volatility = 波动率；Liquidity = 流动性；Margin = 保证金（交易语境）/利润率（财报语境），按上下文
   - Position = 仓位；Long / Short = 多头/空头；Hedge = 对冲
   - Index = 指数；ETF 保留英文；Benchmark = 基准（指数语境）
   - Listing = 上市；Delisting = 退市；IPO 保留英文
   - Default = 违约（债务语境）；Sanction(s) = 制裁
   - Underweight / Overweight = 低配/超配（评级语境）
   - Consensus / Expectations = 市场预期；Beat / Miss = 超出预期/不及预期

2. 以下专有名词**按中文财经惯例翻译或保留**：
   - 机构：美联储 / 欧洲央行（ECB）/ 日本央行（BoJ）/ 英国央行（BoE）/ 美国财政部 / 美国证券交易委员会（SEC）/ 国际货币基金组织（IMF）
   - 指数与产品：标普 500（S&P 500）/ 道琼斯 / 纳斯达克 / 纳斯达克 100 / 罗素 2000 / 费城半导体指数；VIX 保留英文（可写"VIX 恐慌指数"）；QQQ、SPY 等代码保留英文
   - 公司通用规则：有通行中文名的用中文名（苹果 / 微软 / 英伟达 / 特斯拉 / 亚马逊 / 谷歌 / Meta / 博通 / 台积电 / 摩根大通 / 高盛）；没有通行译名的保留英文原文
   - 股票代码（AAPL、MSFT、NVDA、TSLA、AMZN、GOOGL、META、AVGO 等）**一字不改**保留英文
   - 人物：鲍威尔（Powell）/ 耶伦（Yellen）/ 特朗普（Trump）等有通行译名的用中文；没有通行译名的保留原文
   - 数据指标：CPI / PPI / PCE / GDP / PMI 保留英文缩写（首次可括注"消费者价格指数"等），非农就业、初请失业金、成屋销售等按中文惯例
   - 机构研报与投行名：高盛 / 摩根士丹利 / 摩根大通 / 瑞银 / 贝莱德等用通行中文名

3. 代码 / 命令 / URL / 数字单位 **一字不改**保留：
   - 反引号代码 `code` 不翻译；网址原样
   - 数字+单位：3.2%、$500 billion、10-year yield 4.25%、+150 bps、$2 trillion
   - 金额、百分比、点位、倍数、区间必须保留原文的阿拉伯数字和单位；不要把 $2 trillion 改写成"数万亿美元"等中文数量词
   - 日期照原文（ March 11 或 3 月 11 日均可，保持全文一致）；财报季度写法照原文（Q3、第三财季按原文区分 fiscal quarter）

4. 语气纪律：不把"可能"译成"将会"，不把"回撤"译成"崩盘"，不放大或弱化原文对涨跌和风险的措辞。
