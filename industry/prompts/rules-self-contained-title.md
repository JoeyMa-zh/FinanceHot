
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 公司名 / 指数或产品名 / 数据或事件名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代号 / 没信息量的 teaser（如 "The big one"、"What just happened"、"重磅"）时，结合【来源】和正文把主体补进标题。例：原标题 "The decision is out" + 来源 "美联储新闻稿" → "美联储公布最新利率决议"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体公司或数据时，用上位词（如"美国国债收益率""大型科技股"）兜底，绝不凭"市场常识"编一个具体数字 / 公司 / 数据名。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Outlook 这类解释、分析或展望标题，中文标题必须保留这个类型；不能因为正文谈到一个已经发生的数据、决议或行情，就改写成“公布 / 发布 / 决定 / 暴跌”。只有原标题明确宣布了发布、公布、决定或落地，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、公司、数据名。
   例：原标题 "How the Fed's rate path shapes the dollar" → "美联储利率路径如何影响美元"，不能写成 "美联储公布利率决议"。
   例：原标题 "What to watch in Apple's Q3 earnings" + 来源和正文明确是苹果财报前瞻 → "苹果 Q3 财报前瞻：值得关注的要点"，不能只写成缺主体的 "值得关注的要点"。
